# Aditya A. Sapre personal website

Static, multi-page website ready for GitHub Pages.

## Deploy
1. Upload **the contents of this folder** to the root of your GitHub Pages repository (or copy them into your existing site). Keep the `assets/` directory intact.
2. In the GitHub repository settings, open **Pages**, and select **Deploy from a branch → main → / (root)**.
3. Open the Pages URL when deployment finishes.

`index.html` is the homepage. The menu tabs are separate HTML pages with blue styling. The homepage has six original, editable SVG schematics.
